# AudioVerse

- Projeto pessoal do João. PWA em português, com biblioteca em IndexedDB e conexão opcional ao Google Drive para baixar os áudios privados.
- Projeto: C:\Users\joao\Desktop\projetos\AudioVerse. Não alterar o MeuTreino.
- Não enviar áudios, backups pessoais ou relatórios ao repositório público.
- Nesta entrega, o destino definitivo dos audiolivros é o Google Drive privado; o GitHub hospeda o aplicativo.
- PDF, EPUB, textos extraídos e MP3 locais são temporários de processamento. Remover as cópias após a conversão ou após conferir o envio do áudio ao Drive, conforme o tipo de arquivo. Não manter um acervo nos discos do computador.
- Manter um único HTMLAudioElement para reprodução e integrar Media Session sem depender de Web Audio para tocar livros.
- Não prometer reprodução ou retomada com tela bloqueada sem testar no iPhone real.
- Controles de pelo menos 44 px, safe areas e suporte offline após o primeiro acesso.
- Verificar com npm run check, npm test, npm run test:browser e npm run build.
